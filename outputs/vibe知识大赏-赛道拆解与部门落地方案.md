# Vibe 知识大赏 × make-video：赛道拆解与本技能的部门级落地方案

> 起因：@I-20261114-04。先给一句话定位——**「Vibe 知识大赏」不是新东西砸进旧技能，
> 而是旧技能（电影部门制、3-8 分钟长片流水线）与这条新赛道（60 秒单知识点、代码
> 逐帧画、BGM 卡点）之间缺一个"档位"**。本技能的骨架完全够用，缺的是三个具体件：
> 竖屏档位、BGM 网格、一个风格包。下面是全部推导。

## 一、赛道事实（2026-10 调研）

**是什么**：抖音话题「Vibe 知识大赏」（话题播放量 12.0 亿，活动 10-31 截止，
1-10W+ 官方流量扶持），B 站同步在传。画面不是拍的、不是视频模型生成的，
**是 AI 写代码一帧一帧画出来的**。

**风格指纹**（与 make-video 现有风格包的差异项加粗）：
- 深色底（近黑）+ 金色/霓虹线条 + 粒子聚字 + 电影级光晕
- 横竖屏都有，抖音主流是 **竖屏 1080×1920**
- 时长 **60-90 秒**（现技能时长档位是 0-5 / 5-10 / 10+ 分钟，最短 0-5 分钟≈整档）
- **字幕逐词/逐句砸落**（卡拉OK式），像格言一句一句上墙
- **BGM 卡点**：转折点对齐小节线，BPM 驱动剪辑
- 结构：0-2 秒钩子 → 每 10-15 秒一个转折 → 结尾开放问题

**代表数据**：信息论 138 万赞、人生容错率 77.2 万赞、光遗传学 68.9 万赞；
有账号 20 天双平台涨粉 78 万。

**方法论内核**（知乎拆解，通用生产线）：
1. 选题 = 话题页「最热」榜参照 + 一支视频只讲透一个知识点，数据逐条核实出处
2. 标题四套路：反直觉数字 / 追热点 / 戳情绪痛点 / 名言母题；前 2 秒必须砸钩子，第一帧不黑屏
3. **视觉不凭灵感，把爆款关键帧交给 AI 拆成参数**（配色/光线/质感/字幕/节奏/构图）→ 风格沉淀
4. 流程：总指令 → Canvas 动态网页（`render(t)` 时间纯函数）→ 9 静帧自查×2 轮 →
   Playwright 逐帧截图 → ffmpeg 合成 → BPM 对齐 → 总览抽帧检查
5. 声音：剪映音乐库借曲（「开智」感纯音乐）+ Python 合成音效、混音限峰

**开源参照**：
- github.com/worlds3/vibe-knowledge — 纯前端 Canvas + render(t) + 逐帧导出 4K60 + skill
- github.com/wchhywizd/vibe-knowledge-interactive — Agent Skill 形态

## 三、部门级落地方案（七部门 × 具体改动）

> 原则：**不动 7 部门 14 工件的骨架，只加"档位"**。类比：不是再造一辆车，
> 是给现有车加一个"运动模式"挡。

### 制片/工程（P0 基建）
1. **新增时长档位 `short-60`（0-150s）**：
   - `docs/01/03` 档位表 + V-SCP-005 字数校验新增 `short-60` 分支
     （150s ÷ 220ms/字 ≈ 400 字封顶，60s ≈ 273 字）
   - 配方 `short-vibe.json`：beats 固定五拍 `hook → concept → twist → payoff → openQuestion`
     （对应赛道规律：0-2s 钩子、每 10-15s 转折、结尾开放问题）
   - `project.json` 增加 `aspect: '9:16'`（constants 已支持，需让 init/validate 认这个字段）
2. **BPM 网格（V-RHY-BPM）**：`bgm_synth.py` 输出 sidecar `logs/bgm-grid.json`
   （`{bpm, beatMs, barMs, beats:[ms]}`）；`composer.ts` 时间线对齐时提供
   `--align-bgm` 开关，转折点吸附最近小节线（±0.5 拍容差）；`bgm_synth.py`
   增加 `--bpm/--style` 参数（不再固定 84）。

### 编剧部（03）
- 五拍文案模板（钩子/概念/转折/收束/开放问题），每拍字数预算（60s 版：
  12/18/18/8/6 字左右）——填空题，不是自由发挥
- 「一支视频只讲透一个知识点」+「数据逐条核实出处」写进部门检查单
- 标题四套路写进 A1 章程模板

### 导演部（04）
- A3 批注模板新增 `vibe-short` 变体：每拍一个视觉意图，**禁止信息倾倒**
  （60 秒塞三个知识点 = 全部没讲透）
- 转折点 = 剪辑点 = BPM 小节线，三者绑定

### 美术摄影部（05）——**核心新增：vibe 风格包**
- 新风格包 `styles/vibe-cosmos/style.json`（未对拍前 grade B，V-STYLE-005 合规）：
  ```json
  {
    "id": "vibe-cosmos",
    "name": "Vibe 知识大赏",
    "userFacing.aliases": ["vibe", "知识大赏", "粒子聚字", "金色线条", "深空知识风"],
    "palette": { "primary": "#0A0A0F", "accent": "#FFD75E", "neutral": ["#FFD75E","#7C6CFF","#3DD6C3","#E8E8F0","#1A1A24"] },
    "visuals": { "dimension": "mixed", "motifs": ["particle-converge", "golden-line", "glow-title", "karaoke-subtitle"],
                 "sceneBias": ["atmosphere", "typography", "deep-stage", "depth-layers"], "sceneDeny": ["chart.html 族"] },
    "effects": { "grain": 0.10, "vStyle": "cinematic-glow", "bloom": 0.30, "vignette":  "0.25" },
    "transitions": ["dissolve", "whipPan", "smash-cut"],
    "pacing": { "curve": "beat-grid", "shotLenMs": [900, 2600] },
    "anatomy.sound": "BGM 卡点驱动剪辑，转折对齐小节线"
  色板是按爆款关键帧拆的（深黑底 #0A0A0F + 金 #FFD75E + 霓虹紫/青辅助）。
  V-STYLE-005「未对拍不上架」——所以 grade B，实测一条片后按对拍结论升 A。
  ```
- 4 个签名母题进 choreo-lib 或新模板：
  - `particle-converge` 粒子聚字：散粒子按 hash 噪声流到字形轮廓再定格（确定性）
  - `golden-line` 金线生长：SVG stroke-dashoffset 沿路径生长
  - `glow-title` 光晕大字：bloom + 颗粒 + 暗角
  - `karaoke-subtitle` 逐词字幕：字幕按旁白时间戳逐词点亮（复用 emphasis 词级时间戳）
  - （口径统一：choreo-lib 已有确定性噪声与 cam 抖动挂重音，粒子/金线按它写）
- **竖屏构图适配**：`composer.ts` 构图/字幕避让按 9:16 画幅算（主体居中带、
  字幕占下 1/3、keywords 梗卡不压主体）；affects `highlightSentence` 定位与
  `keyword` 梗卡坐标逻辑

### 采购部（06）
- `assetPolicy=auto`（全代码绘制）对 60s 片更顺——60 秒找素材性价比极低，
  赛道惯例就是全画
- BGM 来源三选一：bgm_synth.py 合成 / 剪映音乐库借曲（需授权确认）/ 用户自带

### 声音部（07）
- 五拍配音能量曲线：钩子(高)→概念(中)→转折(高)→收束(中)→开放问题(低)
- 逐词字幕的时间戳来源：STT 对齐（现有 TTS 管线已能出词级时间戳则直接用；
  否则按字数均摊 + emphasis 词偏移）
- 音效：粒子聚字「沙—」、金线生长「叮」、转场「whoosh」，全部限峰 −1.6dB

### 剪辑部（08）
- `beat-grid` 曲线：切点吸附 BGM 网格（±0.5 拍）；60s 片约 18-22 切（镜长
  900-2600ms），呼吸镜间隔放宽到 4
- 转场词表沿用现七类；dissolve 用视觉轨重叠实现（现机制），60s 片 dissolve 占比 ≤40%

### 剪辑/工程验收（新增校验）
- V-RHY-BPM：切点-小节线偏差 ≤ 0.5 拍，超了拦
- V-SCP-005 short-60 档：字数 ∈ 400 字 ±20%
- V-CAP-003（新）：逐词字幕词时间戳单调不减
- 竖屏：9:16 时 V-COMP 系列按竖屏构图带重算

## 四、两步走

**第一步（本周可做，1-2 天）**：不开新档位，用现有管线手做一条：
- recipe=science-explainer，5 拍压进 60s，voice qwen3，style 用
  keynote-minimal 变色（深底金强调）
- 产出：一条 60s 竟品对拍片 + 一份「差距清单」——哪些母题画不出来、哪些校验误伤
- 判据：成片挂抖音/B站看数据，与爆款对拍构图/节奏/字幕密度

A/B 判断「现管线做 60s 竖屏」离爆款还差哪几档，再决定第二步的投资强度。

**第二步（立项改造，3-5 天）**：按第三节的方案立项改造：
- P0：short-60 档位 + BPM 网格 + vibe-cosmos 风格包 + karaoke 字幕
- P1：竖屏构图适配 + 音效梗库 + 编舞母题 ×4
- P2：标题/文案五拍模板、采购三选一 BGM 流程

## 五、为什么不另起一个新技能

1. **管线同构**：HyperFrames（GSAP timeline + 逐帧 seek + ffmpeg）就是赛道说的
   「Canvas 加态网页 + Playwright 逐帧截图 + ffmpeg 合成」，是同一件事的工程化。
2. **choreo-lib 已是 adu-motion-video 秎植**——赛道里「阿杜 next」的动效底座
   本技能已经有了，缺的是参数与档位，不是能力。
3. **部门制在 60s 片上照样成立**：60 秒片各部门填空更简单（字数预算更紧、
   转折更明确），不是推倒部门制。
4. **风格沉淀流程现成**：爆款关键帧 → 参数化 → provenance/absorb → 对拍升级，
   正是 style.json 的设计用途。

## 七、通俗版总结（给老板的一分钟）

你看到的那些爆款（信息论 138 万赞那条）**就是 AI 写代码一帧一帧画出来的**。
我们的 make-video 技能本来就是干这个的——电影部门制流水线，代码绘制成片，
管线 80% 现成，连「阿杜 next」的解析式编舞层都已经移植过来了（choreo-lib）。

缺三个件：**60 秒竖屏档位、BGM 卡点网格、vibe 风格包**（深黑底金线条粒子聚字
逐词字幕）。

两步走：本周先用现有管线手做一条 60s 对拍片验证差距；然后立项改造补三个件，
3-5 天。不另起新技能——加一个"运动模式"挡，不是再造一辆车。

活动 10-31 已截稿，但这套打法通用，换话题照样能发。
