## 这次按你的三条意见改了什么

### 1. 「就只有一个小点」→ 改成分级标注

第一版 18 镜全是同一种 8px 圆点 + 文字，一屏十几个，地图等于背景。现在按语义分三类表达：

| 语义 | 画法 | 用在哪几镜 |
|---|---|---|
| **面**（这一片是什么） | 闭合多边形 + 12-16% 半透明填充 + 虚线描边 + 质心注记 | 青藏高原（s01a/s01b/s05a/s05b）、黄土高原（s01b/s02b/s06a）、华北平原（s02b/s03a）、东北平原（s03a）、四川盆地（s07a）、塔里木盆地（s08a/s08b） |
| **线/方向**（水往哪流、山往哪走） | 折线 + 端点箭头 + **流动虚线动画** | 黄河几字弯（s01b/s06a/s09b）、长江（s01b/s07a/s09b）、珠江（s08a/s08b）、三条横向山系（s02a）、四条纵向山系（s03a/s09b）、四条源流（s05b） |
| **点**（就是这个地方） | 圆点 + 文字，一屏 ≤2 个 | 壶口、夔门、宜宾、唐古拉 |

区域顶点按**真实边界经纬度**取（每 2-4 经度一顶点），不是随手画框——青藏高原的形状观众认得出来。

**机检证据**（每镜在镜内 65% 处抽帧，统计标注像素占比）：

```
s01a 琥珀0.36%  s01b 琥珀0.27%  s02a 琥珀0.31%/青0.13%  s02b 琥珀2.28%
s03b 琥珀0.50%/青4.45%  s04a 琥珀0.46%  s06a 琥珀1.31%  s09b 琥珀0.39% …
有标注的镜头 = 18/18
```

### 2. 「放大缩小很生硬，能否取消」→ 全片禁止变焦，只做平移

这不是调参数能解决的：**只要 scale 随时间变，观众就读成变焦**，幅度再小、缓动再柔也一样。所以做了硬性改造：

- 机位轨的 `scale` 在单镜内**恒定** = `SCALE_HOLD`（1.06，只用作平移余量防止露边）
- `coverage`（覆盖切）的 `scale` 一律折成 1——换机位只靠位移和旋转表达
- 景别（ELS/MS/CU…）不再决定"放大到多少"，只决定恒定过扫量
- 原来靠缩放表达的六个运镜分支（push-in / pull-out / dolly-in/out / crane-up/down / punch-in / drift）全部改为**纯位移**，语义保留（"推"= 向主体方向平移，"拉"= 背离主体平移）

**机检证据**：`logs/camera-rig.json` 里 18 镜共 60 个机位分段，`from.scale` 与 `to.scale` 全部等于 1.06，**没有任何一段发生缩放**。

### 3. 「应该用我的个人配音」→ 这条上一版做错了

上一版 18 镜的 `voice.voice` 字段是 `auto`，走的是 edge-tts 默认音色，**没用你的克隆音色**。原因是我直接调了 `voice --shot`，那条路径读的是 `MV_TTS` 缺省值。

这一版改用 `scripts/run-voice.mjs`（它会把 `personal/profile.json` 里的 qwen3 + 参考音频 + 逐字稿注入环境），18 镜全部重录：

```
unique voices: qwen3        ← 你的克隆音色
total voice: 168.5s
```

## 这轮修掉的三个真实 bug（都不是配置问题）

1. **`<path>` 没包 `<svg>`**：区域形状与动线**从未渲染过**——上一版"地图主轴"其实只有底图 + 圆点，线一条都没显示。
2. **`<div>` 塞进 `<svg>` 不渲染**：修好上一条后，s01a 的三条色带整块消失（琥珀像素回落到 0.07%）。改为 `splitBody()` 按顶层标签分流：SVG 放 path/text，HTML 层放 div。
3. **坐标系混用**：百分比坐标配像素 stroke-width 会让描边粗细随宽高比变形。统一改成 `viewBox="0 0 1920 1080"` + 经纬度→百分比→像素的单一路径。
