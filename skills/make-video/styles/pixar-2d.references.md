# 皮克斯 2D 卡通（pixar-2d）· 风格档案

## 适用场景
- kids-education

## 视觉参数镜像
> 以下字段由 `pixar-2d.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | hard-cut / dissolve |
| 偏好场景 | paper-stage / comparison |
| 禁用场景 | deep-stage / iso-stage / chart |
| 母题 | squash-stretch / anticipation / round-form / expressive-face |

## 视觉语法
- 圆润友善形体 + 挤压拉伸与预备动作 + 夸张表情；角色即情绪。
- 明亮原色 + 暖中性；圆形=友善、尖角=对立；轮廓清晰、边缘柔和。
- 2D 圆润形体，中近景看清表情；禁止 3D 痕迹与机械版式。

## 代码可达边界
- B 级：位移类原则（squash/stretch/anticipation/overshoot）可复现；角色表情 rig 与表演节奏为工艺天花板。
- 首条成片对拍后按 V-STYLE-005 结论升级。

## 来源与等级
- 等级 B（未对拍）：动画十二原则公开教学与制作特辑要点。
