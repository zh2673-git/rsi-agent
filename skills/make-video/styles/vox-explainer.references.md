# Vox 解释型科普（vox-explainer）· 风格档案

## 适用场景
- science-explainer
- news-brief

## 视觉参数镜像
> 以下字段由 `vox-explainer.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | hard-cut / dissolve |
| 偏好场景 | chart / hierarchy-stack / flow / process-track |
| 禁用场景 | atmosphere / comic-symbol / paper-stage |
| 母题 | flat-icon / color-code / zoom-hierarchy / step-reveal |

## 视觉语法
- 扁平图标 + 单一强调色编码 + 层级缩放 + 分步揭示；把复杂议题拆成可视信息结构。
- 中性浅底 + 严格色码（同一概念永远同色）；图形层缩放代替机位运动。
- 2D 信息图/流程/层级可视化主导，禁立体与氛围空镜。

## 代码可达边界
- A 级：图表/流程/层级模板与平面矢量代码完全可达，颜色编码写进 IR 审计。
- 首条成片对拍后按 V-STYLE-005 结论归档。

## 来源与等级
- 等级 A：Vox 解释型新闻扁平矢量信息图语法公开拆解。
