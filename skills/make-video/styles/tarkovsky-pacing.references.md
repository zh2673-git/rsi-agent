# 塔可夫斯基极慢节奏（tarkovsky-pacing）· 风格档案

## 适用场景
- documentary-mood

## 视觉参数镜像
> 以下字段由 `tarkovsky-pacing.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | dissolve |
| 偏好场景 | atmosphere / deep-stage |
| 禁用场景 | chart / comparison / kinetic-type / comic-symbol / paper-stage |
| 母题 | rain-field / water-ripple / smoke-drift / ember-glow |

## 视觉语法
- 极慢长镜（6-12s）+ 自然元素（雨/水/风/火）+ 诗性凝视；时间本身是主角。
- 一镜一元素，低饱和自然色 + 高对比低调光；声音与画面不同步（J-cut 留白）。
- 只用 pacing 曲线与元素氛围，letterbox 宽银幕；拒绝节拍网格与信息倾倒。

## 代码可达边界
- C 级：仅 pacing 曲线（极慢长镜/呼吸结构/切点稀少）可用；画面工艺与作者性不在代码可达范围。
- 不声称复现作者风格。

## 来源与等级
- 等级 C（未对拍）：公开影评与拍摄札记要点，仅 pacing 层参数化。
