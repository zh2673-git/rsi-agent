# 口播大字幕梗（talking-head-punch）· 风格档案

## 适用场景
- short-vibe

## 视觉参数镜像
> 以下字段由 `talking-head-punch.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | hard-cut / smash-cut |
| 偏好场景 | kinetic-type / typography |
| 禁用场景 | deep-stage / atmosphere / paper-stage |
| 母题 | punch-subtitle / word-pop / kinetic-word / emphasis-scale |

## 视觉语法
- 关键词逐词弹出 + 字号强调缩放 + 与语音同步的字幕节拍；字就是画面主角。
- 深底亮字高对比 + 单一强调色标重点；背景只做节奏衬底。
- 2D 动态排版，逐词 stagger 弹入、重音 scale-punch；禁立体、禁氛围空镜抢戏。

## 代码可达边界
- A 级：文字形态与运动（动态排版分类法）+ 卡点同步代码完全可达。
- 全片 slam/punch ≤1/3 镜（V-MOT-013）；首条成片对拍后归档。

## 来源与等级
- 等级 A：知识口播与动态排版逐词强调语法公开拆解。
