# 王家卫霓虹抽帧（wongkar-wai）· 风格档案

## 适用场景
- story-narrative
- documentary-mood

## 视觉参数镜像
> 以下字段由 `wongkar-wai.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | dissolve / whip-pan |
| 偏好场景 | atmosphere / depth-layers |
| 禁用场景 | chart / hierarchy-stack / comic-symbol |
| 母题 | step-print / motion-blur / warm-neon / off-center-frame |

## 视觉语法
- 浓艳暖冷霓虹（绛红/墨绿/昏黄）+ 暗部丢失；慢门拖影与晃动光斑制造迷离。
- 偏心构图：人物置于画框边缘，用空间留白表达疏离；钟表/霓虹提示时刻。
- 长镜凝滞与骤切交替；抽帧靠关键帧稀疏化；mixed 维度仅用于纵深走廊，不声明纯 3D 母题。

## 代码可达边界
- B 级：色调、光晕、慢动作、偏心构图可复现；step printing 抽帧工艺与色彩手调为工艺天花板。
- 不声称复现作者性，首条成片对拍后按 V-STYLE-005 结论升级。

## 来源与等级
- 等级 B（未对拍）：公开影像拆解可用于参数化。
