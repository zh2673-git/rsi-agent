# 新海诚空气感（shinkai-atmosphere）· 反模式

- **转场**：本风格只允许 dissolve / whip-pan；禁止使用其他转场类型。
- 禁止把天空压成一片纯色——无渐变与体积光空气感消失。
- 禁止人物特写占满画面——留白给天与光是签名。
- 禁止用 3D 立体字或机械透视偷渡空气感；光效为 2D 参数层。
- 禁止冷硬黑场与强对比剪影——那是 noir-contrast，不是空气感。
- 母题通过 **prompt 表达约束**（god-ray 斜射 / lens-bloom 光晕 / sky-gradient 渐变 / reflective-puddle 倒影）写进分镜提示，不要求模板硬编码。
