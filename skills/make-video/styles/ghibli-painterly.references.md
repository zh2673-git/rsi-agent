# 吉卜力绘本感（ghibli-painterly）· 风格档案

## 适用场景
- kids-education
- story-narrative

## 视觉参数镜像
> 以下字段由 `ghibli-painterly.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | dissolve / whip-pan |
| 偏好场景 | atmosphere / process-track / compare-stage |
| 禁用场景 | chart / hierarchy-stack |
| 母题 | watercolor-wash / soft-sky / hand-drawn-line / cozy-interior |

## 视觉语法
- 水彩晕染 + 手绘线描 + 柔和天空；色温偏暖，边缘保留轻微不规则笔触。
- 自然与日常空间为主体：草地、窗边、街角；细节繁而柔，不堆高对比霓虹。
- 2D 绘本层叠，禁止立体机械字打破手绘统一性。

## 代码可达边界
- A 级：水彩纹理、柔边、手绘抖动线、暖色渐变、层叠视差均由代码程序化生成。
- 边界：逐帧手绘笔触与复杂角色表演为工艺天花板，不声明为已兑现。

## 来源与等级
- 等级 B（未对拍）：公开拆解可用于参数化，首条成片对拍后按 V-STYLE-005 结论升级。
