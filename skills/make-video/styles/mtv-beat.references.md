# MV 卡点混剪（mtv-beat）· 风格档案

## 适用场景
- short-vibe

## 视觉参数镜像
> 以下字段由 `mtv-beat.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | smash-cut / whip-pan / hard-cut |
| 偏好场景 | kinetic-type / typography / comparison |
| 禁用场景 | atmosphere / paper-stage / flow |
| 母题 | beat-pulse / strobe-flash / split-screen / speed-ramp |

## 视觉语法
- 强节拍切点 + 频闪 + 分屏 + 速度渐变；切点吸附 BPM 小节线（±0.5 拍）。
- 高对比撞色 + 涂鸦式图形；多风格快切拼贴靠统一色板收住，避免乱。
- 2D 图形层按节拍驱动，禁止真实素材打断统一节奏视觉。

## 代码可达边界
- B 级：节拍网格、频闪、分屏代码可达；多风格拼贴统一性与速度渐变工艺有边界。
- 全片重音 ≤1/3 镜（V-MOT-013）；首条成片对拍后按 V-STYLE-005 结论升级。

## 来源与等级
- 等级 B（未对拍）：节奏蒙太奇语法公开拆解可用于参数化。
