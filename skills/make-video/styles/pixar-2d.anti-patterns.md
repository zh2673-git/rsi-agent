# 皮克斯 2D 卡通（pixar-2d）· 反模式

- **转场**：本风格只允许 hard-cut / dissolve；禁止使用其他转场类型。
- 禁止机械立体字与 3D 透视——这是 2D 圆润卡通。
- 禁止只用字幕表达情绪——挤压拉伸与表情动作才是主体。
- 禁止深空/等距场景与信息图——那是其他风格的地盘。
- 禁止尖角形体做友善主体——圆形语言是签名。
- 母题通过 **prompt 表达约束**（squash-stretch 挤压拉伸 / anticipation 预备动作 / round-form 圆润形体 / expressive-face 夸张表情）写进分镜提示，不要求模板硬编码。
