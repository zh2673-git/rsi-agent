# 王家卫霓虹抽帧（wongkar-wai）· 反模式

- **转场**：本风格只允许 dissolve / whip-pan；禁止使用其他转场类型。
- 禁止均匀居中构图——偏心留白是疏离感签名。
- 禁止中性平光——浓艳暖冷霓虹与暗部丢失是基调。
- 禁止声明纯 3D 母题；mixed 仅用于纵深走廊，非机械立体字。
- 禁止快切节拍网格——情绪长镜与骤切交替，不跟 BPM。
- 母题通过 **prompt 表达约束**（step-print 抽帧 / motion-blur 拖影 / warm-neon 暖冷霓虹 / off-center-frame 偏心）写进分镜提示，不要求模板硬编码。
