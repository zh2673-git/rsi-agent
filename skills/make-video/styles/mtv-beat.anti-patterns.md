# MV 卡点混剪（mtv-beat）· 反模式

- **转场**：本风格只允许 smash-cut / whip-pan / hard-cut；禁止使用其他转场类型。
- 禁止游离节拍的切点——一切落点吸附 BPM 小节线。
- 禁止氛围长镜与纸感——那是 atmos/绘本，不是 MV。
- 禁止用 3D 立体字；频闪与分屏为 2D 层。
- 禁止全片重音超过 1/3 镜（V-MOT-013）。
- 母题通过 **prompt 表达约束**（beat-pulse 脉冲 / strobe-flash 频闪 / split-screen 分屏 / speed-ramp 速度渐变）写进分镜提示，不要求模板硬编码。
