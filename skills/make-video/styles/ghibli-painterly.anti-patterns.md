# 吉卜力绘本感（ghibli-painterly）· 反模式

- **转场**：本风格只允许 dissolve / whip-pan；禁止使用其他转场类型。
- 禁止高饱和霓虹与硬边矢量——那是 neon-tech-cinematic，不是绘本。
- 禁止把水彩做成纯色平涂——无晕染与笔触即丢失手绘感。
- 禁止用 3D 立体字或机械透视；绘本为 2D 层叠。
- 禁止冷峻黑场强对比——那是 noir-contrast，不是 cozy interior。
- 母题通过 **prompt 表达约束**（watercolor-wash 晕染 / hand-drawn-line 手绘线 / soft-sky 柔天 / cozy-interior 暖空间）写进分镜提示，不要求模板硬编码。
