# 古典连续性剪辑（classical-continuity）· 风格档案

## 适用场景
- story-narrative
- documentary-mood

## 视觉参数镜像
> 以下字段由 `classical-continuity.json` 机器对账，改动须同步两边。

| 字段 | 值 |
| --- | --- |
| 转场 | hard-cut / dissolve |
| 偏好场景 | compare-stage / process-track |
| 禁用场景 | comic-symbol / kinetic-type / chart |
| 母题 | shot-reverse-shot / match-cut / eyeline / axis-180 |

## 视觉语法
- 180° 轴线 + 正反打 + 视线匹配 + 动作中切；透明不露痕迹的叙事语法。
- 先定轴线再分镜，越轴必须有动机（角色移动/转场）；景别阶梯随对话节奏推进。
- 这是剪辑语法包而非美术包：切点动机写进分镜与 cut-audit，画面保持自然低对比。

## 代码可达边界
- A 级：轴线/机位/切点审计由 coverage 与 camera rig 表达；演员表演连续性不在代码范围。
- 首条成片对拍后归档。
