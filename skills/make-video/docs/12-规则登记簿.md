# 12 · 规则登记簿（P13 阶段4）

> 本文件是「规则=已踩坑登记簿」的落盘载体，取代被元审视判定为过度归纳的「三层宪法」。
> `docs/10-视觉与剪辑规范.md` 仍是 V-* 编号的**唯一权威**；本登记簿只做「重审结论 + 归层 + 反例 + 归属」，**不新增 V-* 编号**（媒介承诺除外）。

## 一、登记卡五问（每条规则一张）

① **目标**：保护什么表达？说不出来 = 删。
② **适用域**：哪些语境成立？域外不成立。
③ **反例**：合法违反场景。找不到反例的审美规则默认可疑（「静止占比 60%」即此病）。
④ **证据**：实测 / 参照背书。
⑤ **硬度**：硬约束 / 默认值 / 偏好+覆写口子——连续谱，不是抽屉。

**归层原则**：
- 媒介承诺（工程底线：音画同步、时间真源、字幕可读、渲染可复现、失败不伪造）→ V-* 笼子，少而稳；
- 审美领域没有永远错的手法 → 登记簿 + 覆写口子；
- 规则面向过去（踩过什么坑），动机面向未来（空隙怎么决策）。

## 五、声明必接线纪律

任何写进 schema / 文档 / 风格包的声明字段，必须有消费方；「声明未接线」比「没有声明」更糟（pacing.curve 20 处 no-op 的教训）。
- 已接线：emotionMap（resolveEmotionVisual + motion-audit.emotion）、constraints.maxPunchOut（punchOutAudit + V-CAM-005 warn）、pacing.maxStaticRatio（validateIntraShotMotion + 消融对拍）。
- 登记但不接线（合法）：drift 三义、main=第二拍、duration 口径——它们是「约束解释」，不是「声明字段」。
