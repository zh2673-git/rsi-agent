# make-video 视觉与剪辑规范（公共法律）

> 本篇是 **V-\* 不变量的唯一权威登记处**。各部门（03-09）只引用、不重复定义；
> 风格包与配方（11）只能在这些不变量的参数空间内取值；违反即阻断，无例外。
>
> 理论谱系：场面调度 / 动画十二原则 / 格式塔 / 蒙太奇与 Walter Murch Rule of Six /
> 声画对位 / 认知负荷理论 / 动态排版传统（Saul Bass 一脉）/ Ed Hooks 动画表演 /
> 编剧结构理论（Syd Field、Save the Cat）/ **信息设计（Tufte 数据墨水）** /
> **多媒体学习原则（Mayer）** / 古典好莱坞连续性剪辑（默认叙事语法）。
> 校验器编号规则：V-<域>-<序号>；实现于 `src/core/validators/`；单测全覆盖。

## 总则

1. 规范管"不许做什么"，风格包（11）管"偏好什么"，配方（11）管"这类视频通常怎么配"。
2. 每条不变量三要素：**规则 / 理论出处 / 校验方式与失败处理**。
3. 校验失败分级：`error`（阻断装配/渲染）与 `warn`（记录不阻断，进反模式统计）。
4. 域与主管部门对应（角色视角的落地）：

### 5.3 动效语法与重音预算（P7，吸收阿杜 + 花叔）

> 核心命题：**动效不是"哪里都加"，而是落在该落的词上**。丰富 ≠ 每句都砸。
> 实现：`src/domain/motion-grammar.ts`（`pickGrammar` / `actionSheet` / `auditMotionMix`），
> 审计结果落 `logs/motion-audit.json`，compose 阶段有 error 即拦。

| ID | 规则 | 出处 | 校验 |
|---|---|---|---|
| V-MOT-013 | **重音预算**：带重音标点（slam/punch/whip）的镜头 ≤ 镜头数 1/3 | 花叔 lint ⑯ | error：按场景实际调用的原语数计 |
| V-MOT-014 | 不连三镜往里推（推进去了要找机会拉出/横移） | 花叔 lint ⑮ | error |
| V-MOT-015 | 推近次数/分钟 ≤ 8 | 花叔 film_gate 黄灯线 | error |
| V-MOT-016 | 文字主导镜 ≤ 30%（否则是 PPT 不是视频） | 花叔轨道档第 1 条 | error |
| V-MOT-017 | 单镜 2–6s（0-5 档位） | 花叔「一镜 2–6 秒」 | warn |
| V-MOT-018 | 开头 3 秒是具体小场景，不是标题 | 花叔「开头 3 秒不是标题」 | error：`auditOpening` |
| V-MOT-019 | 每镜 ≥1 主动作；同语法不连 ≥3 镜；语法多样性下限（单一非 b_roll 语法全片，或头部语法占比 >55% → warn） | 阿杜 motion-quality | error |
| V-MOT-020 | 相邻两镜换构图（不换画风） | 花叔 | warn |
| V-MOT-021 | **每镜必须有 `MV.motifLoop`**（母题循环） | 阿杜「每幕 1 主动作 + 2 母题循环」、花叔「画一直是活的」 | error：canvas 程序镜豁免 |

**V-MOT-021 为什么是 error**：入场动作再漂亮也只占开头约 1 秒，剩下 4 秒没有循环运动，
成片就是「动一下、然后死掉」。这条不是口味问题，是可测量的：
2026-11-05 实测三支案例的相邻帧变化像素占比（Δ≥3 灰阶，16:9 网格）——

| 案例 | 修复前 | 修复后 |
|---|---|---|
| A 动效语法（`flow` 模板 7 镜全无 motifLoop） | 3.0–5.4%（只左侧小方块在动） | 26.5–89.8%（整屏热区全亮） |
| B 留白高级感 | 3.3–5.3% | 3.8–17.1%（受极简风格约束，见下） |
| C 记忆瓶颈 | 3.4–6.5% | 4.1–29.1% |

**母题振幅的定价规矩**（写模板时照此取值，别写 0.2 量级）：
- `float` 的位移是 `amp*6` px → `amp` 必须 ≥ 0.6（否则 ±1.8px，肉眼不可见）
- `pulse`/`rotate` 是 `amp/8`、`amp*3` 的比例/角度 → `amp` 取 0.6–1.0
- `shimmer`/`drain` **不吃 amp**（改的是透明度区间），写在细线元素上等于没动
- 载体必须有视觉权重：**1px 细网格、2px 描边、16% 透明度纹理上做任何运动都看不出来**。
  选载体要挑画面里本来就有的大面积元素（光晕/地面/背景板/色带），而不是新贴一层装饰。

**未实现的 kind 必须显式告警**：`motifLoop` 曾只实现 `float/pulse/rotate/shimmer`，
模板里按语义写的 `sweep/breathe/scan/drain/compress/settle/drift` 共 18 处调用
全部静默落进 `else` 变成 ±1.6px 位移——这正是「画面死了」的直接原因。
现在 11 种 kind 全部实现，未知名一律 `console.warn`，绝不静默降级。

| ID | 规则 | 出处 | 校验 |
|---|---|---|---|
| V-MOT-022 | 母题**可见**：amp 折算位移 ≥ 3px，且每镜 ≥1 种母题（过半镜无母题才告警） | P8（渲染实测 amp 0.3=静止） | warn |
| V-MOT-023 | LLM 场景必须调用动作谱 `requiredPrimitives` 点名的原语 | P8（动作谱变约束） | error：仅 LLM 施工路径；forge 模板路径豁免（模板选型与语法选型是两条链） |

**十一种镜头语法**（`pickGrammar` 按旁白语义打分，并**硬排除**冲突项；真实 id 见 `GRAMMARS`）：
`y1_flat_explainer` 扁平科普 / `y2_collage` 拼贴 / `y3_whiteboard` 白板 /
`y4_story` 故事快切 / `y5_kinetic_type` 动态字 / `y6_mechanism` 机制拆解 /
`y7_system_map` 系统地图 / `t1_3b1b` 形变不切 /
`t2_keynote` 一屏一事 / `t3_finance` 财经图表 / `b_roll` 氛围兜底。

**语法前移（P8-T2）**：`pickGrammar` 在**分镜期**执行并写入 `visual.params.actionSheet`；
compose 期只沿用不重算（导演/人工在确认点改过的语法不被覆盖）。文字主导闸：
前文 y5 超过 40% 配额后硬排除 y5（`suppressTextLed`），重音是稀缺资源。

**动作谱八字段**（阿杜，落 `visual.params.actionSheet`，是"这一镜怎么动"的可审计凭据）：
对应口播 · 主体 · 准备动作 · 主动作 · 刹停收势 · 配角让位 · 相机路径 · 声音落点。
P8 追加第十字段 `requiredPrimitives`（语法→必选原语映射，全语法必含 motifLoop）；
LLM 画场景时 payload 带全谱，校验按 V-MOT-023 验收。

**超长镜切分（P8-T6）**：旁白 >36 字（≈8s）且含 ≥2 句的镜，分镜期按句界拆为 a/b 两镜，
后半镜景别进一档（`ZOOM_LADDER`）；V-RHY-007 口径同步为「每个 segmentId 至少一镜覆盖」
（拆分镜共享原 segmentId，旁白拼接=原段）。

### 十二b、跨镜运动连续性与节奏曲线（2026-11-14 新增，ID 复用说明）

> 原十二表的 V-CON-001~005 管「同场景内」连续性；本节是**跨镜运动维度**的扩展。
> 为避免与既有 ID 冲突：跨场景运动轴审计的告警编号为 **V-CON-003（运动轴）** 与
> **V-CON-004（转场节奏）**（场景内道具/字幕连续性不受影响）；节奏曲线偏离审计为
> **V-CON-002（节奏）**（场景内色温一致性不受影响，仍由原 V-CON-002 复检表把关）。
> 三条新判据全部 warn 级、落 logs/continuity-audit.json，不阻断出片。

| ID | 规则 | 出处 | 校验 |
|---|---|---|---|
| V-CON-003（运动轴） | 相邻镜机位矢量夹角 >90°（点积 <0）→ warn：出入画方向打架；静止/漂移镜是方向重置，不参与 | 广告/预告片剪辑通识（运动同向或静止接运动） | warn：logs/continuity-audit.json |

**节奏曲线（pacing.curve 可执行化）**：`pacing.curve: "0.9,0.6,0.4,0.7"` = 按幕均分的能量目标
（0-1，钩子高 → 展开 → 沉潜 → 收束回升）。选型时低能量幕排除高能量语法（t3/y5/y6）、
高能量幕排除低能量语法（b_roll/y4/t1）；V-CON-002（节奏偏离）审计全片语法能量均值 vs 曲线
均值，偏离 >0.25 → warn「声明的节奏形状没被选型执行」。

**一镜到底（T3a v1）**：相邻镜 `transition: "oneshot"`（或 `continuity`）= 声明「这两镜是同一
连续长镜的节拍段」——无操作转场（不重叠不渲染过渡），机位按矢量接力（同向加深/正交转向），
审计层豁免「同语法连 3 镜」「相邻同构图」。词表校验豁免：它不是「怎么接」的选择，是结构声明。
