# 07 领域专章（刑事 / 行政 / 宪法）

> 解决的问题：民事的通用流程套到刑事和行政上会出结构性错误——证明标准、审查对象、法定义务全都不一样。**这一篇只在对应领域触发。**

## 一、刑事专章

### 三阶层（不可用"四要件"混着说）

```
构成要件该当性 → 违法性 → 有责性
```

顺序不能倒：先看是不是这个罪，再看有没有违法阻却（正当防卫/紧急避险），最后看有没有责任阻却（责任年龄/责任能力/违法性认识）。

**打回信号**：报告写"构成犯罪，但情节轻微"却未区分违法性与有责性 → 层次混乱。

### 罪刑法定三条硬红线

| 红线 | 含义 |
|---|---|
| 禁止类推（不利） | 存疑即认定不构成，不得类推入罪或加重 |
| 禁止习惯法入罪 | 只能依成文刑法 |
| 禁止不定期刑 | 法定刑幅度内量刑 |

### 量刑必给区间

```
量刑起点 → 基准刑 → 调节情节 → 宣告刑（区间）
```

**必查情节**：自首、坦白、立功、累犯、退赔谅解、认罪认罚、未遂/中止、从犯/胁从。
**追诉时效**属 P2，须在程序性前置阶段先算，不能等到量刑。

### 刑事特有失败模式

| 场景 | 动作 |
|---|---|
| 罪与非罪存疑 | 按存疑有利于被告，认定不构成，并写明存疑原因 |
| 此罪与彼罪竞合 | 分别涵摄后按法条竞合规则处理（references/04） |
| 刑民交叉 | **并行分析**：民事部分不因涉刑而自动中止（除法定先刑后民情形） |
| 单位犯罪 | 须同时检视单位与直接责任人员 |

## 二、行政专章

### 审查对象是"合法性"，不是"对错"

行政诉讼的审查基准是**行政行为合法性**，法院原则上不代替行政机关作合理性判断（除明显不当）。

### 合法性审查六项（逐项作答，缺项即报告不完整）

| # | 审查项 | 不成立的后果 |
|---|---|---|
| 1 | 主要证据是否充分 | 认定事实不清 |
| 2 | 适用法律法规是否正确 | 适用法律错误 |
| 3 | 是否违反法定程序 | 程序违法 |
| 4 | 是否超越职权 | 无权处分 |
| 5 | 是否滥用职权 | 目的不当 |
| 6 | 是否明显不当 | 裁量失当 |

**程序违法的独立价值**：即使实体结论正确，程序违法也可导致撤销。**打回信号**：报告只评实体、不查程序 → 行政案件分析不合格。

### 行政特有必查项

| 项 | 说明 |
|---|---|
| 职权来源 | 是否有法律、法规、规章授权；是否有委托（委托须有依据且以委托机关名义） |
| 说明理由义务 | 决定书是否载明事实、理由、依据 |
| 告知与听取陈述申辩 | 是否履行（重大事项还须听证） |
| 送达 | 是否依法送达（影响起算点，直接影响 P2） |
| 裁量基准 | 是否有裁量基准、是否说明偏离理由 |

### 行政规范性文件的附带审查

行政行为所依据的规范性文件（非法律、法规、规章）可在诉讼中一并请求审查。触发条件见 references/02 的「行政规范性文件触发条件」。

## 三、宪法基本权利专章

### 审查框架（三阶）

```
1. 保护范围：该行为是否落入某项基本权利的保护领域
2. 限制：是否构成对该权利的限制（含事实上的限制）
3. 正当化：限制是否有法律依据（法律保留）+ 是否合乎比例原则
```

### 比例原则三阶（顺序不可跳）

| 阶 | 问题 | 不通过即违宪 |
|---|---|---|
| 适当性 | 手段能否促进目的 | 不能 → 不适当 |
| 必要性 | 是否有同等有效且侵害更小的手段 | 有 → 不必要 |
| 均衡性（狭义比例） | 侵害与所得是否成比例 | 失衡 → 过度 |

### 法律保留

限制基本权利须有**法律**依据；行政法规、地方性法规、规章不得创设限制。

**打回信号**：以"某某规定"（非法律）作为限制基本权利的依据 → 违反法律保留。

## 四、跨领域竞合处理

| 竞合 | 处理原则 |
|---|---|
| 刑民交叉 | 并行分析；民事不自动中止；同一事实的认定可相互参考但不互相拘束 |
| 行民交叉 | 先判断行为性质（三要件）；行政行为合法性是民事裁判的先决问题时，可能需中止 |
| 行刑交叉 | 行政处罚与刑罚可并存（罚款折抵罚金），不违反一事不再罚 |
| 民宪交叉 | 宪法一般不直接适用于私主体间（除有明确规定的领域） |
