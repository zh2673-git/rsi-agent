# 05 抗辩、证据与后果量化

> 解决的问题：结论出来以后，还有三件事能推翻它——抗辩、证据、以及后果算不出来。

## 一、抗辩三分法（按请求权生命周期排）

| 类型 | 作用 | 例子 | 检视顺序 |
|---|---|---|---|
| 权利未发生抗辩 | 否认请求权产生 | 合同未成立/未生效、意思表示不真实 | 1 |
| 权利消灭抗辩 | 承认曾发生，但已消灭 | 已履行、抵销、免除、混同 | 2 |
| 权利受阻抗辩 | 请求权存在但暂不能行使 | 时效抗辩（**计算见 S2/P2，此处只判是否被主张、是否放弃**）、同时履行抗辩、先诉抗辩 | 3 |

**顺序不能乱**：先查有没有，再查还在不在，最后查能不能行使。跳过前两步直接讲时效，是常见错误。

## 二、法律行为效力状态

| 状态 | 含义 | 后果 |
|---|---|---|
| 有效 | 成立且生效 | 按约定产生效力 |
| 无效 | 自始、当然、确定无效 | 不得履行；已履行须返还 |
| 可撤销 | 撤销前有效，撤销后自始无效 | 须在除斥期间内行使 |
| 效力待定 | 取决于追认或拒绝 | 相对人可催告 |
| 未生效 | 已成立但未满足生效条件/未批准登记 | 条件成就时生效 |

**打回信号**：报告写"合同无效，可以撤销" → 无效与可撤销是互斥状态，混用即结论错误。

## 三、证据三性与证明标准

**三性**：真实性（形式真实 + 内容真实）、合法性（主体/程序/形式）、关联性。

| 领域 | 证明标准 |
|---|---|
| 民事 | 高度盖然性 |
| 刑事 | 排除合理怀疑 |
| 行政 | 明显优势证据 |

**举证责任**：原则"谁主张谁举证"；例外须明确指出（举证责任倒置、法律推定、法院依职权调取）。

## 四、证据发现（C→E 映射）

```
构成要件 C → 待证事实 F → 证据材料 E
           → 获取主体/渠道 + 证明力等级 + 获取难度 + 优先级
```

| 证明力 | 典型材料 |
|---|---|
| 强 | 行政机关盖章文件、不动产登记簿、公证文书、裁判文书、银行原始流水 |
| 中 | 合同原件、银行流水、聊天记录原始载体、发票、快递单 |
| 弱 | 手写便条、复印件、单方陈述、利害关系人证言 |

**每条材料必须给获取渠道**，否则用户无法执行。只推荐材料不给出处 = 未完成。

### 证据反例（真实高频）

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 只列材料不说去哪取 | 每条标获取主体/渠道 |
| 2 | 把复印件与原件证明力等同 | 区分并提示补强 |
| 3 | 忽略公文书证的强证明力 | 优先推荐行政机关盖章文件 |
| 4 | 不按要件映射，堆砌材料 | 逐要件映射 |
| 5 | 主证据取不到就卡死 | 每个主证据给至少一条替代/补强 |
| 6 | 推荐非法取证 | 只推合法渠道，非法渠道明确警告 |

## 五、后果量化

### 民事赔偿

四层推导：基础后果 → 调整因素（法定/酌定）→ 竞合/聚合 → 区间结果。

常见项目：医疗费、误工费、护理费、交通费、住院伙食补助费、营养费、残疾赔偿金、死亡赔偿金、精神损害抚慰金、被扶养人生活费。

**计算公式必须标数据来源**：当地上一年度统计口径、伤残系数、赔偿年限、责任比例。缺任一项 → 只给区间并列出缺失数据，不给单一数值。

> 具体条文号与年度标准一律走 references/02 的条号纪律，不凭记忆写。

### 刑事量刑

```
量刑起点 → 基准刑 → 调节情节（自首/立功/累犯/退赔谅解/认罪认罚） → 宣告刑
```

**必须给区间**，不给单点。法定刑幅度是硬边界，不得突破。

### 行政处罚裁量

从轻（幅度内较低）/ 减轻（低于下限，须有法定事由）/ 从重（幅度内较高）。

**打回信号**：给出精确到元的单一赔偿数额而无任何区间和假设 → 未完成。

## 七、失败模式

| 场景 | 动作 |
|---|---|
| 某要件无对应证据 | 标「证据缺位」，给举证责任倒置/法律推定/申请法院调取三条路径 |
| 材料在对方或第三人手里 | 提示申请法院调取或调查令 |
| 行政机关拒不提供 | 给政府信息公开、行政复议、行政诉讼三条救济 |
| 涉及国家秘密/商业秘密/隐私 | 标注限制，建议不公开审理或保密质证 |
| 证据严重不足 | 标「证据不足」，写明谁承担不利后果 |
| 缺少量化必要数据 | 列缺失项 + 给假设条件下的区间 |
| 地区标准不明 | 标「需按当地标准调整」，不猜数字 |
