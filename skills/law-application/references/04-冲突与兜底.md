# 04 冲突裁决与兜底适用

> 解决的问题：两条法条都能用，选哪条？没条文能用，怎么办？**这是"两个都对时选哪个"的问题，也是 AI 最容易随机选一个的地方。**

## 一、四类冲突

| 类型 | 表现 | 归属规则 |
|---|---|---|
| 法条竞合 | 同一事实同时满足多个规范的构成要件 | 本篇第二节 |
| 法源冲突 | 不同位阶或同位阶规范内容不一致 | 本篇第二节 |
| 证据矛盾 | 不同证据指向相反 | 本篇第四节 |
| 争点冲突 | 多个争议焦点需排序 | 本篇第三节 |

## 二、法条竞合与法源冲突的裁决规则

| 规则 | 内容 | 适用前提 |
|---|---|---|
| 上位法优于下位法 | 高位阶优先 | **不同位阶**冲突 |
| 特别法优于一般法 | 特别规定优先 | **同一位阶**且存在特别/一般关系 |
| 新法优于旧法 | 新规范优先 | **同一位阶、同一事项** |
| 法不溯及既往 | 行为时法优先 | 时间效力冲突（从旧兼从轻属刑事特例） |

**规则有适用顺序，不能乱套**：

```
先比位阶（不同位阶 → 上位法胜，到此为止）
  ↓ 同位阶
再看是否特别/一般（是 → 特别法胜）
  ↓ 无特别关系
再看新旧（同一事项 → 新法胜）
  ↓ 时间效力问题
查溯及力（从旧兼从轻）
```

**打回信号**：用"特别法优于一般法"去裁不同位阶的冲突（例如用部门规章压法律）→ 规则用错，结论作废。

## 三、争点排序

程序先于实体；前提先于派生；主要先于次要；法律问题先于事实问题。

**为什么**：程序问题不解决，实体分析可能是白做（管辖错了，后面全废）。所以报告里争点顺序本身就是结论质量的一部分。

## 四、证据矛盾的裁决

| 情形 | 处理 |
|---|---|
| 可用证明力规则分出高下 | 按证明力（原件>复制件、公文书证>私文书证、无利害关系>有利害关系） |
| 证明力相当且矛盾不可调和 | 标「事实真伪不明」，按**举证责任**分配判其不利后果 |
| 一方证据不足 | 该方承担不利后果，不"各打五十大板" |

**注意**：真伪不明不是"和稀泥"，必须明确写出谁承担举证不能的后果。

## 五、兜底适用

### 兜底类型

| 类型 | 例子 | 限制 |
|---|---|---|
| 概括条款 | 诚实信用、公序良俗 | 须说明为何具体规则不足 |
| 类推适用 | 民法漏洞填补 | 民法可用，**刑法禁止不利类推** |
| 兜底条款 | "其他…"式规定 | 须同类解释（不能无限扩张） |
| 基本原则 | 比例原则、法律保留 | 仅作论证依据，不单独作为处罚依据 |

### 穷尽具体规则的三项证明（缺一不得兜底）

1. 已检索并**列明**被排除的具体规则及排除理由；
2. 具体规则存在**真漏洞**（不是"我不喜欢这个结论"）；
3. 兜底适用不会破坏法律安定性。

**打回信号**：报告直接跳到"依据诚实信用原则"，前面没有任何具体规则检索记录 → 拒绝兜底，退回 references/02。

### 兜底的硬红线

| 红线 | 说明 |
|---|---|
| 刑法禁止不利类推 | 不得通过类推入罪或加重处罚；存疑即认定不构成 |
| 处罚法定的底线 | 行政处罚不得以"原则"代替法定构成要件 |
| 法律保留 | 限制基本权利须有法律依据，不得以规范性文件替代 |

## 七、失败模式

| 场景 | 动作 |
|---|---|
| 既有规则解决不了冲突 | 标「需司法解释或裁判规则」，降置信度，**不自行创设规则** |
| 证据矛盾无法调和 | 标「事实真伪不明」，写明举证责任归属 |
| 涉及宪法性冲突 | 建议提交有权机关，不自行裁决 |
| 多个冲突相互嵌套 | 分步解决，每步标注依赖关系（B 的结论依赖 A） |
| 想兜底但没穷尽 | 拒绝兜底，退回检索 |
| 兜底会破坏安定性 | 降置信度，建议立法或司法解释 |
