# 01 事实与定性（含程序性前置）

> 解决的问题：用户给的是生活叙事，法律要的是要件事实；而且在拆事实之前，有两件事一旦漏掉，后面全部白做——**管辖**和**时效**。

## 一、三层事实结构

```
原始叙述（生活叙事）
    ↓ 提取与筛选
法律相关事实（有规范意义的事实单元）
    ↓ 类型化与对应
要件事实（可直接对应构成要件）
```

**打回信号**：报告里出现"大约""据说""可能是"这类词去承载一个要件事实 → 未完成。

## 二、九类事实单元

| 事实类型 | 核心问题 | 常见证据来源 |
|---|---|---|
| 主体 | 何人？有无主体资格/行为能力 | 身份证、营业执照、登记信息 |
| 行为 | 做了什么？（作为/不作为） | 合同、转账记录、决定书、往来函件 |
| 时间 | 何时？**含时效起算点** | 合同日期、邮戳、系统日志、送达回证 |
| 地点 | 何地？（含管辖连接点） | 登记地址、现场照片、GPS |
| 对象 | 指向什么？ | 发票、交付凭证、许可证 |
| 结果 | 产生什么后果？ | 鉴定意见、病历、催告回执 |
| 因果 | 行为与结果有无联系？ | 鉴定意见、连续事件记录 |
| 主观 | 故意/过失/明知/应知/善意 | 聊天记录、邮件、公示材料 |
| **程序** | 采取了什么程序行动？**含是否已过异议期/起诉期** | 送达回证、受理通知、复议决定 |
| **约定/条款** | 有无书面约定？还款期限/利率/违约金/争议解决/担保如何约定？ | 借条、合同原件、补充协议、聊天记录 |

**最低覆盖**：主体、行为、时间、结果四类不可缺。缺任一类 → 触发 QC1 回溯。
**涉合同/借贷/合伙类案件**：约定/条款类不可缺——还款期限直接决定时效起算点，争议解决条款直接决定 P1 管辖。

## 三、事实属性四分法（净化）

| 属性 | 识别标志 | 处理 |
|---|---|---|
| 客观事实 | 具体行为/时间/地点/对象 | 保留，标注可能证据来源 |
| 主观判断 | "我觉得""显然""肯定" | 剥离情绪，追问客观事实 |
| 法律评价 | "构成欺诈""属于违约" | **还原为支持该评价的客观事实** |
| 背景信息 | 性格、无关前因后果 | 剔除 |

**打回信号**：事实清单里出现"构成违约"这类结论词 → 说明评价混进了事实，退回净化。

## 四、程序性前置（原框架缺失，必须补）

在进入实体分析前，按顺序回答三个问题。任一为"否"，实体分析全部作废：

| # | 问题 | 不通过的后果 |
|---|---|---|
| P1 | **管辖**：地域/级别/专门管辖是否正确？仲裁条款是否排除诉讼？（仲裁条款以第 3 节「约定/条款」格为准，缺失即无法判断） | 程序驳回，实体不审 |
| P2 | **时效/期间**：诉讼时效、除斥期间、行政复议/起诉期限、追诉时效是否已过？起算点如何认定？**有无中断/中止事由？** | 抗辩成立即败诉；刑事则不起诉 |
| P3 | **前置程序**：是否需先经行政复议、劳动仲裁、行政裁决、政府信息公开申请？ | 起诉被裁定不予受理 |

**为什么必须前置**：时效与管辖是**法院可依职权审查**的事项，不是"对方提了才查"。原框架把时效埋在"抗辩"里，等于把主动权交给对方，实务上是败诉主因之一。

### P2 必做的三段计算（缺一即 P2 未做）

```
① 起算点：权利受损害之日 / 知道或应当知道之日 / 约定履行期限届满之日
② 变动：中断（主张权利 / 对方同意履行 / 提起诉讼或仲裁）→ 从中断时重新起算
        中止（不可抗力等障碍）→ 障碍消除后满法定期限届满
③ 届满日：起算点（含中断后重新起算） + 法定期间 = 具体日期
```

| 时效变动类型 | 典型事实 | 举证责任 |
|---|---|---|
| 中断——权利人主张权利 | 催告函、微信/短信催讨、律师函、上门催收 | 主张中断的一方（通常是原告） |
| 中断——义务人同意履行 | 承诺还款、部分履行、对账确认、请求延期 | 同上 |
| 中断——提起诉讼/仲裁 | 起诉状、受理通知（含申请支付令、诉前调解） | 同上 |
| 中止 | 不可抗力、无法定代理人、继承未定等障碍 | 主张中止的一方 |

**必查**：当事人说"他一直说还""我催过"这类表述时，不能只当成背景情绪，必须落到**具体时间点 + 载体**（哪一天、微信还是电话、有无书面），否则中断无法认定，时效照常届满。

**打回信号**：
- 报告第 2 节 P2 行没有"起算点 → 届满日"的日期计算 → P2 未做；
- 第 3 节事实裁剪的「时间」格没有对应的时效变动节点（若有催讨行为）→ P2 未做。

## 五、四域定性

| 领域 | 主体关系 | 核心问题 | 典型救济 |
|---|---|---|---|
| 民事 | 平等主体 | 权利/义务/责任归属 | 诉讼、仲裁 |
| 刑事 | 国家追诉嫌疑人 | 犯罪成立与刑罚 | 控告、公诉 |
| 行政 | 行政机关与相对人 | **行政行为合法性** | 复议、诉讼 |
| 宪法基本权利 | 国家权力与公民 | 基本权利限制与合宪性 | 申诉、合宪性审查申请 |

### 行政行为识别三要件（须同时满足）

| 要件 | 说明 | 反例 |
|---|---|---|
| 主体 | 行政机关或法律法规授权组织 | 政府作为民事主体签约 |
| 权力 | 行使行政职权（处罚/许可/征收/强制/审批） | 内部人事任免 |
| 外部性 | 对相对人权利义务产生外部影响 | 机关之间公文往来 |

三要件不全 → 标注「疑似行政行为」，不自动进入行政合法性六项审查（见 references/07-领域专章.md）。

### 常见竞合

刑民交叉、行民交叉、行刑交叉、民宪交叉。**竞合不择一**：并行分析，分别出结论，再在冲突裁决阶段统一（见 references/04-冲突与兜底.md）。

## 六、S1–S3 判定表（QC1 / QC2 / QC3）

| 检查点 | 段 | 通过标准 | 失败动作 |
|---|---|---|---|
| **QC1** | S1 | 事实类至少覆盖主体/行为/时间/结果；涉合同类案件含约定/条款类；主观判断与法律评价已净化。**只查事实是否齐备，不要求给出 P1–P3 结论** | 输出已提取要素 + 待补充清单，暂停 |
| **QC2** | S2 | P1/P2/P3 三项均有明确结论；P2 含"起算点→变动→届满日"计算（有催讨的须含中断认定） | 不通过即终止，不做实体分析 |
| **QC3** | S3 | 主领域明确；行政行为三要件逐条检视；竞合已标注；民事已走九阶 | 回退 QC1 补事实 |

## 七、失败模式

| 场景 | 动作 |
|---|---|
| 信息严重缺失 | 输出已提取事实 + 关键待补充问题清单，暂停流程 |
| 叙述内部矛盾 | 标注争议事实，**不自行调和** |
| 大量情绪化表达 | 剥离情绪后提取客观事实，情绪本身不进报告 |
| 无法判断某事实的法律意义 | 保留原始表述，标「法律意义待判断」 |
| 跨法域因素 | 标注法域适用范围，建议当地执业律师 |
