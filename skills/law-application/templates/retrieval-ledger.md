# 检索台账

> 用途：把每一条法条与案例逐条登记。**报告正文引用的每一条，都必须在此有对应行。** 这是"条号纪律"的落地载体。

## 一、法条台账

| # | 名称 | 条文号 | 版本（通过/施行） | 效力状态 | 检索层级 | 来源（URL/库ID） | 检索时间 | 核实 |
|---|---|---|---|---|---|---|---|---|
| N1 | | | | VALID | L1/L2/L3 | | | ☐已核实 ☐待校验 ☐效力存疑 |

**效力状态取值**：`VALID` 现行有效 / `AMENDED` 已修正（引现行版）/ `REPEALED` 已废止（禁作现行法）/ `UNCERTAIN` 无法确认。

**规则**：
- `核实=待校验` 或 `效力存疑` → 正文对应处必须同步标注，且不得作为唯一结论依据；
- `REPEALED` → 正文只能作历史沿革说明，并写出替代规范；
- 检索层级为 L3 → 该行 `核实` 必须为「待校验」。

## 二、案例台账

| # | 案号 | 法院 | 层级 | 相似度 | 相似理由 | 裁判规则 | 来源 | 检索时间 |
|---|---|---|---|---|---|---|---|---|
| C1 | | | 指导性/公报/参考性/一般 | 高/中/低 | | | | |

**规则**：
- 无案号 → 不得作为案例引用；
- 相似度"高"必须写出至少 3 个匹配维度（案由/法律关系/争议焦点/事实特征/法院层级）；
- 层级为"一般裁判"时，正文不得用"司法实践普遍认为"这类表述。
