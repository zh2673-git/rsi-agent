# law-application — 法条适用分析

## 它产出什么

一份**结构化法律分析报告**（骨架见 references/06），不是"法律意见"。报告可被人读懂、被人逐条复核、被律师直接接续工作。

合格标准一句话：**把报告交给一个执业律师，他能在半小时内复核完所有法条与推论，而不必重做一遍**。

## 何时不用

| 情况 | 去哪里 |
|---|---|
| 只要起草文书（起诉状/合同/答辩状） | 不是本技能，那是文书起草 |
| 只要查某条法条原文 | 直接检索，不必走全流程 |
| 已有一审判决，只要写上诉理由 | 需要程序法专项技能 |
| 商业决策/合规咨询 | 本技能只做法律适用，不做商业判断 |

## 三条硬纪律（违反任一即交付不合格）

1. **条号纪律**：条文号未经官方源核实，写 `第〔待校验〕条`，绝不凭记忆写"第 X 条"。
2. **程序前置**：实体分析之前必答管辖、时效、前置程序三项；不答不做实体。
3. **降级声明**：报告第 0 节写明本次检索用了 L1/L2/L3 哪层、有多少条未核实。

## 流程（12 段 S1–S12，顺序固定）

QCn 恒定对应 Sn，判定表在 `引用` 列所指文件的对应小节；找不到该表 = 该段未做。

| 段 | 做什么 | QC | 判定表在 | 不过怎么办 |
|---|---|---|---|---|
| S1 | 事实裁剪（九类事实 + 属性净化 + 约定/条款） | QC1 | 01 §六 | 输出待补充清单，暂停 |
| S2 | 程序性前置（管辖/时效/前置程序） | QC2 | 01 §四、§六 | 不通过即终止，不做实体 |
| S3 | 法律关系定性（四域 + 行政行为三要件 + 竞合） | QC3 | 01 §六 | 领域不明则并行标注 |
| S4 | 规范检索（四要素 + 效力状态 + 条号纪律） | QC4 | 02 §七 | 回退 S3 或降级声明 |
| S5 | 案例检索（案号 + 层级 + 相似度） | QC5 | 02 §七 | 无类案则声明检索条件 |
| S6 | 涵摄（P-F-C + 中项 + 四谬误自检） | QC6 | 03 §七 | 回退 S4 或转 S7 |
| S7 | 法律解释（文义→体系→目的→历史） | QC7 | 03 §七 | 无需则声明理由 |
| S8 | 冲突裁决（位阶→特别→新旧→溯及力） | QC8 | 04 §六 | 回退 S6 |
| S9 | 抗辩与效力检视（三分法） | QC9 | 05 §六 | 成立则调整结论或回退 S1 |
| S10 | 证据发现与评估（C→E 映射 + 三性） | QC10 | 05 §六 | 证据缺位则给救济路径 |
| S11 | 后果量化（区间 + 数据来源） | QC11 | 05 §六 | 无法量化则定性 + 列缺失数据 |
| S12 | 兜底适用（穷尽证明 + 红线） | QC12 | 04 §六 | 未穷尽则退回 S4 |

**"本阶段无需…"必须给理由**，不能只写一句省略。

**时效的唯一归属**：计算在 S2（P2），抗辩主张在 S9（只判是否被主张、是否放弃）。冲突以 S2 为准。

## 检索降级

L1 法律 MCP → L2 官方源联网 → L3 模型知识（全标 `[待校验]`）。
**每次降级必须写进报告第 0 节。** 详见 references/02。

## 输出前自检

- [ ] 第 0 节有检索层级与未核实条目统计
- [ ] 无凭记忆的条文号（要么已核实，要么 `第〔待校验〕条`）
- [ ] 管辖与时效已作答
- [ ] 每个要件落在满足/不满足/存疑三格之一，无"基本满足"
- [ ] 三段论可独立复核（遮住结论仍推得出）
- [ ] 每个案例有案号，每条证据有获取渠道
- [ ] 量化给区间与数据来源，不给单一精确数
- [ ] 置信度有依据（对照 references/06 第二节）
- [ ] 有免责声明，且它没有替代实质分析

## 验收标准（交付前逐条打勾）

> 机检以 `skill.json` 的 `acceptance`（a1–a10）为准，本表为其人读版，两处条数与内容一一对应。

| # | 判据 | 怎么核 | 不过怎么办 |
|---|---|---|---|
| 1 | 条号纪律零违规 | 全文搜索 `第\d+条`，每处都能在规范检索表里找到对应来源行 | 改为 `第〔待校验〕条` 或补来源 |
| 2 | 程序前置已作答 | 报告第 2 节含管辖、时效、前置程序三项明确结论 | 补做；不通过则终止实体分析 |
| 3 | 检索层级已声明 | 第 0 节写明 L1/L2/L3 与未核实条目数 | 补声明 |
| 4 | 要件三格归位 | 涵摄表每个要件只有满足/不满足/存疑，无模糊表述 | 重判该要件 |
| 5 | 三段论形式有效 | 遮住结论，大小前提仍能推出结论 | 重做或改判 |
| 6 | 法条四要素齐全 | 名称+条文号+版本+效力状态，缺一即不合格 | 补齐 |
| 7 | 案例有案号 | 无案号的引用一律视为未完成检索 | 补检索或删引用 |
| 8 | 量化有区间与来源 | 赔偿/量刑均给区间 + 数据来源 + 假设条件 | 补数据或改给区间 |
| 9 | 抗辩三分法覆盖 | 权利未发生/消灭/受阻抗辩逐项检视 | 补检视 |
| 10 | 置信度有依据 | 与 references/06 置信度表逐条对应 | 重判置信度 |

**反例（一律判不合格）**：凭记忆写条文号；把已废止法规当现行法；事实清单里混入"构成违约"这类评价；只分析侵权不走九阶；结论对但三段论推不出；不做时效管辖；只列证据材料不说去哪取；赔偿额给单一精确数；"根据相关法律规定"；兜底条款当首选；刑法做不利类推。

## 免责声明

本技能输出的是**结构化法律分析草稿，不构成法律意见，不替代执业律师**。
所有法条、案例、解释结论均须经官方法律数据库复核。涉及重大财产、人身自由或复杂程序事项，必须咨询执业法律专业人员。
