# 05 深入层：单镜深潜

> **解决的问题**：用户说"就从庄子/福柯/孙子那个角度深说"。本篇定深潜的七步与交付形状。
> **铁律**：深潜是**用这一副镜把这件事重新看一遍**，不是介绍这套思想。凡出现"某某认为……"而落不到本题事实，即为跑题。

## 一、七步（顺序不可换）

| # | 步 | 要产出什么 | 不过怎么办 |
|---|---|---|---|
| 1 | **锁镜** | 明确本次只用一副，写出体系名、类码、其"适用问句" | 若用户说"综合讲讲"，退回总纲层（`04`） |
| 2 | **取原典** | 从 `01`/`02` 该卡取 1-3 处原文（篇目精确），作为这副镜的**操作依据** | 找不到原文依据 → 该体系不适合此问题，换镜或降为"借用其方法"并声明 |
| 3 | **化方法** | 把该卡"方法"栏的 3-4 步**具体化到本题**，每步写出本题中对应的操作 | 化不出来 → 说明这副镜不适用于此题，如实说 |
| 4 | **推判断** | 走完方法后，对本题给出明确判断（该/不该、是/不是、往哪走） | 得不出判断 → 检查是否漏了方法某步；仍不行则写"这副镜在此问题上给不出判断，因为___" |
| 5 | **认盲区** | 明确这副镜**在本题上**漏掉的具体一项，并说漏掉后结论会怎么错 | 写"有局限"这类套话即不合格 |
| 6 | **标冲突** | 这副镜的判断与哪副镜相反，分歧前提是什么 | 若确无对立，写明"本镜判断与主流常识一致，其价值在于理由不同：___" |
| 7 | **给可检验** | 一句话：什么事实出现就说明这个判断错了 | 无此句则整段降为"参考意见"，不许当结论 |

## 二、输出骨架

```
## 从〈透镜名〉看
### 1. 锁镜
（体系名 + 类码 + 其"适用问句"；一句话说明为什么选它）

### 2. 这副镜的操作依据（原典）
（引 1-3 处，篇目精确；一句话说明它们在这副镜里起什么作用）

### 3. 把它用到这件事上
（逐步：该卡方法的每步 → 本题中的具体操作 → 中间所得）

### 4. 判断
（明确结论，1-2 句）

### 5. 这副镜的盲区：漏掉了什么
（本题上漏掉的具体一项 + 漏掉会导致结论怎么错）

### 6. 与谁对立
（相反判断 + 分歧前提）

### 7. 什么会推翻这个判断
（一个可观察的事实）
```

## 三、两个完整示例

### 例 A：从老子看"要不要给团队定硬规矩"

**1. 锁镜**：老子〔G〕。适用问句：这件事上，我多做的那部分是不是正在制造问题？选它的理由：用户问的是"要不要加一条规矩"，本质是"加干预会不会反噬"，正是老子的主场。

**2. 操作依据**：《道德经》40 章"反者道之动"——任何强推都会激出反向；78 章"正言若反"——正确的说法常听起来像反话；37 章"道常无为而无不为"——不强加反能成事。

**3. 用到这件事上**
- 第一步（反作用）：定"不再改"的硬规矩 → 反作用是什么？改需求本身不会消失（需求确实会变），它只会**换通道**：从会上公开改，变成会下私下改、或者变成"当初就没定死"的模糊表述。结果是变更不可见。
- 第二步（能否靠减法）：不减"变更"，减"变更的摩擦"。现状下改需求的摩擦很低（一句话就改了），而返工的痛在两周后才到。若把变更的摩擦调到一个**刚好让人先想一下**的水平（如变更需一句话说明"砍掉哪个原需求"），比禁令有效。
- 第三步（是否在回返点）：现在团队是"变更太多"，若强压到"变更零"，按"反者道之动"，接下来会反弹成"什么都不敢定"。所以不宜压到零。
- 第四步（正言若反）：直觉说"要定规矩管住他"，反过来说可能对——"让变更更容易被看见"，比"让变更更难发生"更治本。

**4. 判断**：不要定"通过后不再改"的禁令。改为提高变更的**可见性**（每次变更必须写出被替换的原需求与受影响的工作量），把摩擦加在"看见代价"上而不是"禁止动作"上。

**5. 盲区：漏掉了什么**：它漏掉"激励错配"——若产品经理改需求的收益结构不变（改需求能让他避免挨骂，返工成本不归他），那么即使变更可见，他也会照改，只是每次都在表上留一行。老子的减法在此变成"更清楚地记录错误"而非"减少错误"。

**6. 与谁对立**：与韩非对立。韩非会说：正因人情趋利，光"可见"无用，必须有明文赏罚把成本挂到提出方。分歧前提：老子预设"人一旦看见代价就会自省"，韩非预设"人只对自身损益反应"。

**7. 什么会推翻**：若在提高可见性后的一个月内，变更频率未下降且产品经理明确说"我知道会返工，但必须改"——说明他不是没看见代价，而是收益结构问题，此时老子判断失效，应转韩非。

### 例 B：从福柯看"公司为什么要搞价值观考核"

**1. 锁镜**：福柯〔M/Z〕。适用问句：这套分类靠排除什么来成立？它在生产哪种"正常"，谁因此成为"不正常"？选它的理由：用户问的是考核"有没有用"，但真正的问题是考核在**生产什么**，这需要看权力/知识与排除效应。

**2. 操作依据**：福柯《规训与惩罚》全景敞视（被可能的目光注视而自我规训）；《性史》第一卷"权力/知识"——话语生产"可说与不可说"；两书共同提供对"正常/不正常"划分的考察。

**3. 用到这件事上**
- 第一步（找二元对立）：价值观考核建立的对立是「认同我们 / 不认同我们」，或更细的「有主人翁意识 / 打工心态」。它靠这组区分来定义"我们是谁"。
- 第二步（排除效应）：这组区分把什么排除掉了？它把"我不同意这个决策但我会执行"排除为不可说——因为一旦被问"你认同吗"，诚实回答"不认同"就落在"不正常"一侧。于是考核生产的是**表态的合规**，不是认同。
- 第三步（权力/知识）：考核表本身是一套"知识"——它把"主人翁意识"定义成可观测的行为项。这套知识使一种治理成为可能：不靠命令，靠自我检查。
- 第四步（规训技术）：考核的效力不来自打分，来自**可能被打分**。员工在无人监督时也按考核项行事，这就是全景敞视。

**4. 判断**：价值观考核能有效生产"行为一致"，不能生产"价值认同"，且会系统性地**压低异议的表达**。若目标是前者，考核可行；若目标是后者，考核反向。要得到后者，需要能容纳"不认同但执行"的表述空间。

**5. 盲区：漏掉了什么**：它漏掉"这套考核是否真的有效"——福柯式分析只说明它如何运作与排除什么，不评估其实际效果。可能实际效果很差（大家都在应付填表），而福柯的工具说不出这一点。

**6. 与谁对立**：与亚里士多德/儒家式的德性论对立。后者会说：价值观靠**习惯化**养成（亚里士多德：ethos→德性），考核若与日常实践一致则是养成的一部分；福柯会说：任何可观测的指标都会重构行为指向指标本身。分歧前提：德性论预设"实践可以塑造内在品质"，福柯预设"可观测性本身改变行为的意义"。

**7. 什么会推翻**：若考核项设计得与真实工作无法分离（如考核"是否主动帮同事解决阻塞"，而这在任何情况下都必须做），则指标无法被单独应付，福柯的"指向指标"效应会大幅减弱。

## 四、深潜的三种失败模式

| 失败 | 表现 | 纠正 |
|---|---|---|
| **讲义化** | 大段介绍该思想的历史、流派、争论，本题只在最后一段出现 | 原典只取操作依据，不介绍源流；每段必须落到本题事实 |
| **套话化** | "从庄子角度看，就是要放下执念" | 必须走完方法四步，且给出判断与可推翻条件 |
| **独断化** | 只讲这副镜，不提盲区与对立 | 第 5、6 步是硬要求，缺一则不算深潜完成 |

## 五、多镜深潜的边界

用户可能要求"从三个角度分别深入"。处理：**逐镜串行**，每镜完整走七步，镜与镜之间**不交叉引用**（不要"如上所述，庄子与老子都认为…"）。最后加一节「三镜合看」：
- 三镜在哪一点上**共同**指向同一结论（若有）——这是最强的结论；
- 三镜在哪一点上**互相抵消**——此处必须说"取决于前提，无法合并"。

**不许**把三镜揉成一段"综合来看"。揉合的结果必然是哪一副都不像。
