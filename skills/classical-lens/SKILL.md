# classical-lens — 经典多视角

**一句话**：39 副透镜，先内化（八槽齐）再照；总纲并列，单镜深潜；必须出判断，必须出盲区。

## 何时用 / 何时不用

| 用 | 不用 |
|---|---|
| "从老子/庄子/孔子/康德/福柯角度看这件事" | 要事实核查、数据、法规条文（本技能不核实事实） |
| "多角度分析这个决定/冲突/选择" | 要心理诊断、医疗法律投资建议 |
| "传统智慧怎么看 X" | 只要一句名言装饰（那不需要分析） |
| "我该不该 / 为什么会这样 / 这意味着什么" | 要占卜吉凶（易传在此只作结构分析，绝不占筮） |

## 两种模式

| 模式 | 触发 | 产出 | 读 |
|---|---|---|---|
| **总纲** | 用户给一个问题，要"各视角" | 五段表：问题重述 → 总纲表（主镜2-3+异类1-2，六列） → 真冲突 → 交叉盲区 → 若只取一副 | `references/04-总纲层.md` |
| **深潜** | 用户指定单镜（"就从庄子说"） | 七步：锁镜→原典→化方法→判断→认盲区→标冲突→给可推翻条件 | `references/05-深入层.md` |

## 内化前置（三关，缺一不可用某副镜）

1. **取全八槽**：原典 / 代表命题 / 第一原理 / 核心范畴 / 方法 / 独到贡献 / 盲区 / 适用问句。八槽不齐不得用。
2. **过范畴关**：按该体系的意思用词，禁止直译替换（`references/03` 第三节 14 条）。
3. **先认盲区**：用前就知道它看不见什么，输出必须写出"本题上漏掉的具体一项"。

> "方法"槽是唯一能把思想转成操作的槽；"盲区"槽是唯一能防滥用的槽。这两槽最常被跳过，也最容易让输出变成名言集。

## 选镜（判断，不是检索）

1. **判类**：G 生成 / R 人伦 / Z 治道 / M 名辩 / K 认识 / S 势史 / C 争胜（`references/03` 第一节含 39 套归属全表）。
2. **主镜 2-3 副**，其中至少 1 副取自该类；**异类 1-2 副**（主类与所有主镜的主类不同）。
3. 总纲里必须出现 ≥1 对**真冲突**（位置不限，主镜之间或主镜与异类之间）。
4. **不许**：同类同型重复、只选能得出同一结论的镜子、8 副全上。
5. 问题类型 → 起步镜组见 `references/03` 第二节规则 3。

## 硬纪律（违反即不合格）

| # | 纪律 | 判定 |
|---|---|---|
| 1 | **必须出判断**："需辩证看待/各有道理"不算判断 | 判断列须有该/不该、是/不是、往哪走 |
| 2 | **必须出真冲突**：至少一对不可调和的相反答案 + 分歧前提 | 见 `references/03` 第四节 12 对 |
| 3 | **必须出盲区**：本题上漏掉的具体一项 | "任何理论都有局限"即不合格 |
| 4 | **禁范畴直译**：道≠God、仁≠benevolence、中庸≠折中、无为≠不作为、空≠虚无、良知≠conscience | 跨传统输出须写核对行 |
| 5 | **禁编造原文**：不确定措辞标"大意"，不虚构篇目原句 | 引文须带精确篇目 |
| 6 | **禁多镜揉合**：多镜串行，末节只写"共同指向"与"互相抵消" | 见 `references/05` 第五节 |
| 7 | **不预测吉凶、不替代专业决策** | 见 `references/06` 第五节 |

## 流程

**总纲**：判类 → 选镜 → 逐镜取卡八槽 → 填六列表 → 找真冲突 → 找共同盲区 → 给"若只取一副" → 过 `references/06` 第四节自检。

**深潜**：锁单镜 → 取原典（1-3 处） → 方法逐步落到本题 → 判断 → 盲区 → 对立与前提 → 可推翻条件 → 过自检。

## 验收标准

机检口径以 `skill.json` 的 `acceptance`（a1–a10）为准；本表是其可读版，二者必须一致。judge 型条目（a6/a7/a10）按 `evals/rubric.md` 评分。

| # | 标准 | 机检 |
|---|---|---|
| a1 | 总纲表六列齐全（透镜/先问什么/照见/判断/盲区/置信） | assert |
| a2 | 主镜 ≤3 且含 ≥1 异类镜；表内须标出（"透镜"列前缀 `主`/`异`） | assert |
| a3 | 至少一对真冲突并写明分歧前提 | assert |
| a4 | "交叉处"写出各镜共同盲区 | assert |
| a5 | "若只取一副"给出选择与代价 | assert |
| a6 | 判断列为明确判断，非"需辩证/各有道理" | judge |
| a7 | 盲区为本题具体一项，非套话 | judge |
| a8 | 跨传统时写了范畴核对行，无禁译对 | assert |
| a9 | 深潜走完七步（含第 1 节锁镜），含"什么会推翻这个判断" | assert |
| a10 | 引文篇目精确，不确定标"大意"，无虚构 | judge |
