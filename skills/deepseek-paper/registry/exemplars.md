# exemplars — deepseek-paper

| 片段 | 为什么好 | 可复用结构 |
|---|---|---|
| `Our main contribution includes:` + `Architecture: Innovative Load Balancing Strategy` + bullet | 分组标题先给「阶段: 口号」，bullet 才有落点 | 阶段名: 目标口号 → 2–3 条 bullet |
| `Scores with a gap smaller than 0.3 are regarded as at the same level.` | 容差声明让「同档」可诚实书写，避免夸大 | 主结果表固定挂容差句 |
| `Unsuccessful Attempts` 专节，每条带机制解释 | 申报失败换来信用，且他人可省弯路 | 尝试名 → 预期 → 实际 → 机制解释 |
| `Fortunately, these limitations are expected to be naturally addressed with …` | 承认局限但不承诺时间，把责任外推到生态 | 局限 + 原因 + 外推句 |
| `Note that the aforementioned costs include only the official training …` | 主动限定成本口径，防止读者误读 | Note that + 排他说明 |
