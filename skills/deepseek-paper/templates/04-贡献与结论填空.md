# 贡献组与结论填空（Introduction 贡献段 + 结论三段式）

## 一、贡献段（二选一排版）

### 版式 A：论断式引导 + 分组小标题 + bullet（T 类首选）

```
Our main contribution includes:

<阶段名>: <目标口号>

- <这条 bullet 只有一个机制/一个数字，句式：We <动词> <机制>，which <收益>。>
- <...>

<阶段名>: <目标口号>

- <...>
```

分组名取值（照 DeepSeek 用过的）：
- `Architecture: Innovative Load Balancing Strategy`
- `Pre-Training: Towards Ultimate Training Efficiency`
- `Post-Training: Knowledge Distillation from <X>`
- `Infrastructures: <一句话口号>`
- `Distillation: Smaller Models Can Be Powerful Too`（带修辞的写法，M 类可用）

规则：2–4 组，每组 1–3 条 bullet；`contribution` 用单数（DeepSeek 固定用法，别改成 contributions）。
动词按 03 §3.1 选：`we pioneer …` / `we design …` / `we investigate … and prove it beneficial` / `we adopt …`。

### 版式 B：一句话总纲 + 加粗短语开头（M 类首选）

```
Our contributions are summarized as follows:

**<短语>.**
- <...>

**<短语>.**
- <...>
```

短语取值：`Architectural Innovation.`、`Empirical Validation.`、`Scalability.`、`Alignment for <X>.`、`Public Release.`

## 二、核心结果段（紧跟贡献段）

```
Summary of Core Evaluation Results

- <能力域>: <Model> achieves <s1> on <B1> and <s2> on <B2>, surpassing <基线> by <X% absolute>.
```

每条必须有数字 + benchmark 名；同一数字只能在摘要、贡献段、结论段各出现一次，不得三处写法不一致。

## 三、章节导览段（贡献段之后）

```
In the remainder of this paper, we first <动作> (Section 2). Subsequently, we <动作>,
…
Next, we <动作>, …
Thereafter, we <动作>, …
Lastly, we conclude this work, discuss existing limitations of <Model>, and propose
potential directions for future research (Section <末章号>).
```

自检：`(Section N)` ≥3 处，最大值 = 正文章数。

## 四、结论三段式

```
[段1] In this paper, we introduce <Model>, a <架构> language model with <N> total
parameters and <M> activated parameters, trained on <T> tokens. <一句方法总纲>。

[段2] While acknowledging its strong performance and cost-effectiveness, we also
recognize that <Model> has some limitations, especially on <方面>. Firstly,
<局限1 + 原因>。 Secondly, <局限2 + 原因>。 Fortunately, these limitations are
expected to be naturally addressed with <生态/硬件/社区的发展>。

[段3] <一句长期主义表态>。 In the future, we plan to strategically invest in research
across the following directions.
- We will <方向1>。
- We will <方向2>。
- We will <方向3>。
- We will <方向4>。
```

## 填写检查表
- [ ] 贡献 2–4 组，每组有 bullet
- [ ] 每组标题形如「阶段: 口号」
- [ ] 核心结果每条带 benchmark 名与分数
- [ ] 导览段 `(Section N)` ≥3 且与实章号一致
- [ ] 局限恰好 2 条，每条带原因，末尾有外推句
- [ ] 未来方向 4 条，均以 `We will` 开头
- [ ] 摘要 / 贡献段 / 结论三处数字完全一致
