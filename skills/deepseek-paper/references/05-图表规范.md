# 05 图表：DeepSeek 的图型、表型与 caption 三件套

> 用途：图表是「一眼像不像」的第二判别面。规矩比措辞更机械，照做即可。
> 全部 caption 为原文摘录。

## 5.1 图（caption 在图**下**方）

**caption 公式 = 名词短语（是什么）+ 怎么测/怎么画 + 一句结论**，≥2 句，不用 `we` 开头。

| 图型 | 什么时候必须画 | DeepSeek 原文 caption 范式 |
|---|---|---|
| **主对比图（Figure 1，恒定第 1 图）** | 永远 | `Figure 1: Benchmark performance of DeepSeek-V3 and its counterparts.`（极简，一句话到底） |
| **架构图** | T 类第 2 章第 1 图 | `Figure 2: Illustration of the basic architecture of DeepSeek-V3. Following DeepSeek-V2, we adopt MLA and DeepSeekMoE for efficient inference and economical training.` |
| **演进/多子图** | 机制有 A→B→C 演进 | `Subfigure (a) showcases … Subfigure (b) illustrates … Subsequently, subfigure (c) demonstrates … It is noteworthy that …`（三个不同动词避免重复） |
| **pipeline 图** | 有数据/训练流水线 | `Figure 2: An iterative pipeline that collects mathematical web pages from Common Crawl.` |
| **训练曲线** | 有迭代过程（RL/长训） | 只画被讨论的那条曲线 + 一句话说明趋势 |
| **scaling / 拟合图** | 有跨规模数据 | `The red dashed line is linearly fitted from data points of all models except DeepSeekMoE 16B.`（**必须交代拟合口径与为何排除自己**） |
| **热图/模式图** | 有分组行为观察（专家-领域） | 放附录用 |

子图标注：图内用 `(a)/(b)`；caption 里 `Figure (a) shows …; Figure (b) shows …`。

## 5.2 表（caption 在表**上**方，booktabs：无竖线、三线）

**三种列头范式**：
1. **类别列前置**：`Knowledge / Code / Math / Chinese` 占一列做行分组（V2 Table 2、V3 Table 3）。
2. **指标括号内联**：`HumanEval (Pass@1)`、`GSM8K (EM)`、`MMLU (Acc.)`、`TriviaQA (EM)`——`Benchmark (Metric)` 就是列头字符串。
3. **元信息成行**：`# Total Params`、`# Activated Params`、`FLOPs per 2K Tokens`、`# Training Tokens` 放表左侧行（MoE Table 1、V2 Table 7）。

**caption 三件套 = 是什么 + 怎么测 + 结论一句**（原文）：
> `Table 1: Training costs of DeepSeek-V3, assuming the rental price of H800 is $2 per GPU hour.`（**成本表必给单价假设**）
> `Table 2: Comparison among DeepSeek-V2 and other representative open-source models. All models are evaluated in our internal framework and share the same evaluation setting. Bold denotes the best and underline denotes the second-best. Scores with a gap smaller than 0.3 are regarded as at the same level. With only 21B activated parameters, DeepSeek-V2 achieves top-tier performance among open-source models.`
> `Table 3: Comparison among DeepSeek-V3-Base and other representative open-source base models. … Scores with a gap not exceeding 0.3 are considered to be at the same level. DeepSeek-V3-Base achieves the best performance on most benchmarks, especially on math and code tasks.`
> `Table 1: Evaluation results for validation experiments. Bold font indicates the best. Compared with other MoE architectures, DeepSeekMoE exhibits a substantial performance advantage.`
> `Table 2: Comparison of pipeline bubbles and memory usage across different pipeline parallel methods. F denotes the execution time of a forward chunk, B denotes …`（**符号表塞进 caption**）
> `Table 3: AlignBench leaderboard rated by GPT-4-0613. … Models marked with * represent that we evaluate them through their API service or open-weight model, instead of referring to the results reported in their original papers. Suffixes … denote the timestamps when we called their API.`（**星号/后缀含义必须在 caption 里定义**）

**格式纪律**：
- best **加粗**；V2 主结果表另用 **下划线标 second-best** 并在 caption 声明。
- `Scores with a gap smaller than 0.3 are regarded as at the same level` —— 主结果表的**容差声明是固定项**（V2/V3 均有）。这个习惯极好用：它让你能诚实地写「同档」。
- 消融表 caption 必须写出**结论方向**：`The MTP strategy consistently enhances the model performance on most of the evaluation benchmarks.`
- 成本单位显式：`$ per GPU hour`；`K/M` 缩写（`2664K GPU hours`、`2.788M H800 GPU hours`、`$5.576M`）。
- 缺失值写 `-`，并在正文解释原因（V2 中 Qwen1.5 72B 的 CHID 留空并解释）。
- 是否严格 booktabs 三线：HTML 版无法判字形（**未核实**）；按惯例用三线、无竖线。

## 5.3 表格必备的五类（缺哪类说明素材缺哪块）

| 表 | 列头怎么排 | 来源素材 |
|---|---|---|
| 主结果表 | 类别列前置 + `Benchmark (Metric)` + `# Shots` + 模型列 | 自己的评测 + 基线 |
| 消融表 | 每行一个变体，行名 = 变体描述，末列 Δ | 对照实验 |
| 成本/资源表 | 阶段 ×（GPU hours / 成本 / 单价假设） | 运行日志 |
| 与基线对比表 | 模型 / 参数规模 / 数据量 / 关键 bench | 外部论文与 API 实测 |
| 超参表 | 超参名 / 值 / 备注 | 配置 |

## 5.4 图表的三个反模式

1. **图不承载信息**：画了但正文没有一句引用它（lint 会查「每图/表至少被正文引用一次」）。
2. **caption 只写名字**：`Figure 3: Results.` → 不合格，必须 ≥2 句。
3. **无口径的对比**：图里混放「自己内部框架测的」与「别人论文报的」却不声明。要么统一口径，要么在 caption 明写 `evaluated in our internal framework` 与 `*` 标记来源。

## 5.5 工具

- `paper_figure`：按 DeepSeek 视觉规范出图（三线网格、统一色系、自己那条线/柱突出、无多余边框），输出 PNG/SVG + caption 草稿。
- `paper_table`：从 JSON/CSV 生成 booktabs 风格 LaTeX 表 + Markdown 表，自动 best 加粗、second-best 下划线、`-` 缺失值、caption 组装。
- 两者都把数据先落到 `templates/05-图表数据.json` 的格式，避免手写数字。
