# 06 质检：硬门禁 + 评分 rubric + 反例

> 用途：交付前跑 `paper_lint`，再人工过评分项。**门禁不过不许交付。**

## 6.1 硬门禁（缺一项即判「不像」，机检）

| # | 门禁 | 检法 |
|---|---|---|
| G1 | 摘要含 ≥2 处「分数 + benchmark 名」（如 `88.5 on MMLU`） | 正则 |
| G2 | 参数量成对出现：`total parameters` 与 `activated` 同时出现（T 类；M 类若报模型规模亦适用） | 关键词共现 |
| G3 | 摘要或引言给出训练成本（`GPU hours` / `$`）与数据量（`\d+[TBM] tokens`） | 正则 |
| G4 | 摘要末 1–2 句是开源/权重/代码链接 | 关键词 |
| G5 | 存在 `Our main contribution includes:` 或 `Our contributions are summarized as follows:` + ≥2 个分组小标题 + bullet | 字符串 + 结构 |
| G6 | 引言有章节导览段（`In the remainder of this paper`），且 `(Section N)` 出现 ≥3 次、与实章一致 | 正则 + 一致性 |
| G7 | 无独立 `Related Work` 一级章（A 类除外）；结论章含 `Limitations` 字样 | 标题扫描 |
| G8 | 每个 figure caption ≥2 句；每个主结果表 caption 含加粗规则或同档容差声明 | 结构扫描 |
| G9 | 至少 1 处失败/负面结果申报（`Unsuccessful`、`does not`、`fail`）；成本口径澄清句存在 | 关键词 |
| G10 | 禁用词零命中（见 03 §3.7）；`state-of-the-art` 若出现必带 `among/in/on` 限定 | 正则 |
| G11 | 每张图/表在正文至少被引用一次 | 引用扫描 |
| G12 | `outperforms`/`surpasses`/`significantly better` 每次都能对到账本里的 compare 证据 | 账本交叉 |
| G13 | 出现误差/区间语义（`±`、`error bar`、`s.e.m.`、`s.d.`、`CI`、`95%`、`置信区间`）时，全文必须有一处口径声明（s.d./s.e.m./CI 名称，或 `n = N`、seed 数、独立重复） | 正则（条件式：无统计符号则不触发） |
| G14 | 图注若含误差语义，则该图注内必须给出 `n = …` 或重复数/组数 | 图注扫描（只看 figure，不看 table） |

G13/G14 的判据来自期刊作者指南而非语料（见 `references/05` §5.6）。两条都是**条件式**门禁：
不报统计的稿件不会触发，因此「全绿」不等于「统计口径合规」，只等于「若报了统计则口径齐全」。

## 6.2 评分项（每项 0/1/2 分，≥14/20 为文体合格）

| # | 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|---|
| S1 | 动词纪律 | pioneer/propose/introduce/design/adopt 各归其位 | 有 1–2 处错配 | 借来的东西写成 propose |
| S2 | 数字精度 | 每个数字带单位/口径/推导可复算 | 大体有 | 有裸数字 |
| S3 | 局限写法 | 2 条局限，每条带原因，末尾外推 | 只列局限不说原因 | 无局限或写成免责 |
| S4 | 失败申报 | 有专节且每条带机制解释 | 正文提一句 | 无 |
| S5 | 图表规范 | 三线表 + caption 三件套 + 口径声明齐全 + 误差棒注明是 s.d. 还是 s.e.m. 并给 n | 缺一项 | 图无信息量、或有误差棒却不说是哪种 |
| S6 | 连接词指纹 | Firstly/Secondly 与 bullet 分工正确，递进词不重复 | 有重复 | 全篇 First…Second… |
| S7 | 与既有工作关系 | 三档（adopt/extend/unlike）显式且带 `at the cost of` | 只提名字 | 无 |
| S8 | 诚实度 | 主动承认劣势（`While it trails behind …`） | 只承认 1 处 | 通篇只夸 |
| S9 | 章节骨架完整 | 与所选体裁骨架逐节对应 | 缺 1 节 | 缺 ≥2 节 |
| S10 | 附录 | A 贡献致谢 + ≥1 实质附录 | 只有 A | 无附录 |

## 6.3 典型反例（看到就返工）

| 反例 | 为什么不像 |
|---|---|
| `In this paper, we propose a novel framework that achieves state-of-the-art results.` | 三处违规：套话开场、`novel`、裸 SOTA，且无数字 |
| 贡献写成一段 200 字流水账 | 缺分组 bullet |
| `Our method is much better than baselines.` | 无数字、无口径 |
| Related Work 独立成章且放在第 2 章 | 体裁判错（应并入 Introduction） |
| 结论只复述摘要，不提任何局限 | 缺 G7/S3 |
| 图 5 张，正文只引用 2 张 | 违反 G11 |
| 成本写「训练很快，成本很低」 | 违反 G3，必须给 GPU hours/单价 |
| 全部结果都是自己的内部框架测的，却不声明 | 违反 S5 口径声明 |
