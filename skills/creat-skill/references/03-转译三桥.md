# 03 转译三桥

> 解决的问题：行业里有人、有工时、有职称；AI 里都没有。照搬会变成过度工程，不搬会丢质量。三座桥负责把行业的东西转成 AI 能执行的东西。

## 桥一：角色 → 质量责任容器

一个角色 = **一个检查视角 + 一组判据 + 一个交付物**。

不是职称，不是人设，不是"你是一位资深编剧"这种角色扮演。AI 里没有"人"，但必须有"谁对这类质量负责"。

### 角色卡格式

```
角色：分镜师
对什么质量负责：每个镜头都能被独立执行
判据：一镜一单元 / 景别序列合规 / 同场景轴线一致
交付：shot list
打回信号：同场景轴线断裂、一镜里塞两件事
```

### 合并与拆分的规则

| 情况 | 处理 |
|---|---|
| 两个角色失败模式相同 | 合并成一个检查视角 |
| 纯协调、不产出判断 | 删掉，改成流程里的一个检查点 |
| 只在某一阶段出现的专业 | 降级为那个阶段的一条检查项 |
| 必须独立上下文才做得好 | 才拆成独立 agent |

**铁律：按失败模式合并，不按职称合并。** 电影分 7 个部门是因为人有工时与专长限制，AI 不需要复制这个成本。

## 桥二：工件 → 交接契约

每换一次手、每调一次模型，都是一次翻译。工件是防漂移的锚。

### 工件三律

1. **可校验**：有 schema、清单或明确的必含字段；
2. **可人工编辑**：落在文件或 IR 里，不是黑盒中间态；
3. **有明确消费方**：谁接、接来做什么。没人消费的工件是装饰。

### 必须写清的五项

| 项 | 例子 |
|---|---|
| 生产者 | 导演部 |
| 消费方 | 分镜师 / 美术 / 剪辑 |
| 必含字段 | 每镜旁白、画面规格、景别、动机 |
| 不合格长什么样 | 一镜两件事、缺动机、轴线不一致 |
| 人工触点 | 逐镜微调 |

### 双轨原则

复杂工件要给两版：**人读版**（剧本、方案）+ **机读版**（结构化字段、IR）。
只给一轨，另一侧就要重新翻译一遍，翻译损耗立刻回来。

### 识别翻译损耗点

流程里每出现一次「口头交接」「再讲一遍」「按上次那样」，就是一个损耗点。损耗点必须产出一个工件，否则它就是返工的固定来源。

## 桥三：理论 → 冲突裁决依据

LLM 不缺步骤，缺的是「两个都对时选哪个」。理论真正的用途是裁决，不是装门面。

### 三段式

```
理论 → 判断规则 → 校验信号
```

三段缺一，这条理论就不该留在技能里：

| 段 | 要求 | 反例 |
|---|---|---|
| 理论 | 说清「所以遇到 X 该怎么办」 | "要符合儿童认知" |
| 规则 | 条件 + 判断 + 动作 | "注意年龄适配" |
| 校验信号 | 可观察、可数、可对照 | "感觉不够好" |

正例：

```
理论：不一致理论（铺垫建立预期，转折打破预期）
规则：若把 punchline 提前说，笑话仍然成立 → 反转太弱，重写
信号：把结尾挪到开头，读一遍，还能笑就说明反转失效
```

### 来源分级

| 等级 | 来源 | 怎么写 |
|---|---|---|
| 一级 | 学科经典、国家标准、行业规范 | 可直引，必须注明适用边界 |
| 二级 | 行业惯例、高手实践 | 注明"惯例"，不当定律 |
| 三级 | 个人经验、模型推断 | 标「假设·待验证」 |

### 伪理论识别

问一句：**"所以遇到什么情况，该怎么判？"** 答不出来，就是装饰，删掉。

### 冲突裁决

两个理论打架时，必须写明优先级（例如"安全 > 效果""一致性 > 新颖"）。不写，AI 就会每次随机选一个，表现为"风格漂移"。
